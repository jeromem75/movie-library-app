Movie Library App - v28.5.26
UI v28.5.26 - runtime data-location foundation

Incremental build after v28.5.25. Adds a central runtime path helper so the app can resolve config, database, cache, logs, exports, and backups from one place. The default remains legacy app-local data paths; Application Support mode is available only behind a future explicit marker/config flag.

Safety notes:
- Does not switch live data paths by default.
- Does not move, copy, delete, or modify live database/config/cache files.
- Does not delete, move, restore, edit, or replace the current database/config.
- Does not touch media folders, Tutor files, or the shared Caddyfile.
- Does not add playback, streaming, transcoding, subtitles, or media-client features.
